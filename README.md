# Stopwatch Web App

A simple stopwatch web application built using HTML, CSS, and JavaScript.

## Features

- Start the stopwatch
- Pause the stopwatch
- Resume the stopwatch
- Record lap times
- Reset the stopwatch
- Clear recorded laps when reset

## Technologies Used

- HTML
- CSS
- JavaScript
